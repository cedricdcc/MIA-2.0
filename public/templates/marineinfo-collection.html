🌊 MarineInfo Collection Viewer

Demo of <rdf-display template-id="…" template-styles="…"> rendering IMIS/VLIZ collection RDF — predicate classes drive the visual layout via pure CSS, with no JavaScript post-processing.

How this page works: The <rdf-adapter> fetches ../rdf-data/marineinfo-collection.ttl, filters triples to the collection subject, and fires an rdf-loaded event. <rdf-display> clones #collection-triple once per triple, filling in {predicate-class}, {object-is-uri}, {object}, etc. The injected CSS in #collection-triple-styles assigns a flex order and visual style to each predicate class — keyword chips, dataset cards, person badges — using only CSS selectors and the class names derived from predicate URIs.

🏷️ View the HTML template markup 
<!-- STEP 1: styles for the shadow DOM (needed because template content
     is rendered inside rdf-display's shadow root) -->
<style id="collection-triple-styles">
  .rdf-template-host { display: flex; flex-wrap: wrap; gap: .5rem; … }
  .triple            { display: none; }          /* hide unknown predicates */
  .triple.title      { order: 2; width: 100%; font-size: 1.65rem; … }
  .triple.subject    { order: 5; background: #e3f2fd; border-radius: 14px; … }
  .triple.member     { order: 10; width: calc(33.33% - .35rem); … }
  /* … one rule per predicate class … */
</style>

<!-- STEP 2: the per-triple template -->
<template id="collection-triple">
  <div class="triple {predicate-class}"
       data-predicate="{predicate}"
       data-is-uri="{object-is-uri}">
    <span class="label">{predicate-short}</span>
    <span class="value-text">{object}</span>
    <a class="value-link" href="{object}" target="_blank">{object-short}</a>
  </div>
</template>

<!-- STEP 3: use rdf-display with both attributes -->
<rdf-display
  template-id="collection-triple"
  template-styles="collection-triple-styles"
>
  <rdf-adapter
    src="../rdf-data/marineinfo-collection.ttl"
    subject="https://marineinfo.org/id/collection/619"
  ></rdf-adapter>
</rdf-display>
