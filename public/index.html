MIA 2.0 – RDF Adapter & Display Demo

1. Standalone <rdf-adapter> (auto-discovers describedby)

<rdf-adapter></rdf-adapter>

2. <rdf-display> – list mode (default)

<rdf-display>
  <rdf-adapter src="/rdf-data/example.ttl"></rdf-adapter>
</rdf-display>

3. <rdf-display> – grid mode

<rdf-display display-mode="grid">
  <rdf-adapter src="/rdf-data/example.ttl"></rdf-adapter>
</rdf-display>

4. <rdf-display> – table mode

<rdf-display display-mode="table">
  <rdf-adapter src="/rdf-data/example.ttl"></rdf-adapter>
</rdf-display>

5. <rdf-display> – custom <template>

<!-- template element defined in <head> -->
<template id="triple-card">
  <div><strong>{predicate-short}</strong><br/><span>{object}</span></div>
</template>

<rdf-display template-id="triple-card">
  <rdf-adapter src="/rdf-data/example.ttl"></rdf-adapter>
</rdf-display>

6. <rdf-display> – subject-filtered

<rdf-display display-mode="table">
  <rdf-adapter
    src="/rdf-data/example.ttl"
    subject="https://example.org/dataset/1"
  ></rdf-adapter>
</rdf-display>
